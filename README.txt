THIS IS THE PROJECT TO HIGHLIGHT THE DIFFERENCES IN SIZE OF CAPTURED IMAGE AND THE PREVIEW IMAGE
USING STANDARD PYTHON LIBRARIES LIKE OPENCV MATPLOTLIB PIL TEMPLATEMATCHING

TO RUN THE CODE INSTALL ALL THE REQUIREMENTS IN TO UR SYSTEM
EITHER BY INSTALLING EVERYTHING INDIVIDUALLY
OR BY USING PIP INSTALL requirements.txt	

WHILE RUNNING THE CODE
SET PATH1 AS THE CAMERA CAPTURED IMAGE
SET PATH2 AS THE SCREENSHOT IMAGE/COMPARISON IMAGE

OUTPUT IS IN THE FORM OF TWO PANELS
1 - TO DISPLAY THE CROPPING OF THE SCREENSHOT USING TEMPLATE MATCHING
2 - TO DISPLAY OR HIGHLIGHT THE IMAGES BASED ON SIMILAR DIFFERENCES

AND THE CODE SHOULD BE FINE
